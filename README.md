# Worlds 2026 Swiss Stage Predictor

英雄聯盟 2026 世界賽瑞士輪預測網頁。

- 點隊伍選勝方（再點一次取消）
- 整輪選完按「抽籤」：同戰績隨機配對，避開已交手的對手
- 「重新抽籤」重抽最新一輪、「倒退」(⌘/Ctrl+Z) 回到上一步
- 「隨機本輪」「隨機跑完」快速模擬，「複製結果」輸出晉級名單
- 進度存在瀏覽器 localStorage

純靜態頁面，直接開 `index.html` 或用 GitHub Pages。
